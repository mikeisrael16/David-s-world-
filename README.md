# Мир Давида

Детская браузерная игра от Mikhail Game Studio. Только горизонтальная ориентация.

- **Транспорт** — перетаскивай машины, самолёты и корабли на дорогу, в небо или в воду.
- **Щенки** — рассади щенков по их машинам.
- **Слова** — собери слово из слогов (50+ слов, озвучка, подсказки).
- **Динозавры** — раскраска: 10 динозавров, заливка по нажатию, палитра, ластик.

Играть: https://mikeisrael16.github.io/david-s-world-/

Чтобы игра сразу открывалась на весь экран горизонтально, на телефоне открой ссылку в Chrome → меню ⋮ → «Добавить на главный экран» и запускай с иконки.
